# gggmovespeed

一个极简的魔兽世界移动速度显示插件，实时显示当前角色的移动速度百分比。

## 功能

- 实时显示移动速度百分比
- 自动识别移动模式：跑步 / 坐骑 / 驭龙术 / 飞行 / 游泳 / 德鲁伊变形形态
- 左键拖拽移动位置，位置账号级共享（所有角色通用）
- 正确处理驭龙术速度（`GetGlidingInfo`）与脱战条件加速（如 Trailblazer +30%）
- 兼容战斗/副本内的暴雪「秘密数值」限制，不报错

## 安装

1. 下载 `gggmovespeed` 文件夹
2. 放入游戏目录 `_retail_\Interface\AddOns\`
3. 角色选择界面勾选启用

## 使用方法

- 屏幕中央上方显示速度，格式如 `移动: 130.0%`
- 左键按住文字拖动即可调整位置，松手自动保存

## 兼容版本

- 魔兽世界正式服 12.1.0（至暗之夜）

## 文件说明

- `gggmovespeed.toc` — 插件清单
